典型资料使用流程包括器件参数追溯、BOM 与电路联合核对，以及工程文档准备。每个流程均需确认资料版本，保留来源定位和人工复核记录。

### 建议操作顺序

1. 明确问题对象、版本及所需资料。
2. 选择授权知识库，确认文件已解析并可查看。
3. 提问时说明范围、期望输出和引用要求。
4. 对照来源复核结论，再导出或准备文档。
5. 正式交付前完成组织要求的审核。

| 核对项 | 通过标志 |
| --- | --- |
| 权限 | 使用者角色和资料范围符合预期 |
| 解析 | 文件状态完成，实际内容能打开 |
| 问答 | 关键结论具有可定位、可复核的来源 |
| 产物 | 导出文件能打开，内容和格式符合预期 |
| 发布 | 正式文档按要求完成批准 |
| 信息保护 | 共享和交付材料不包含未授权信息 |

这份清单供用户自查。手册中的界面示例不能替代对本人资料、任务和交付结果的检查。
