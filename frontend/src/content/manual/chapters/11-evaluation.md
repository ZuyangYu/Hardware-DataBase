RAGAS 评估由具备权限的系统管理员操作，入口为“治理与运营 → RAGAS 评估”。先准备并绑定正确知识库及匹配的数据集，再按页面步骤执行预检和创建任务。

### 检查评估结果

预检有阻塞项时先处理原因。任务创建后关注运行状态，完成后核对结果和适用范围；没有匹配样本、未通过预检或尚未运行，均不能视为已取得有效评分。

![图 15 RAGAS 评估示例界面](/help-assets/v2.2/images/15-evaluation.png)

### 排查常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 页面或内容不可访问 | 账号角色、部门及知识库权限 |
| 文件无法使用 | 上传来源、格式和解析状态 |
| 回答无法完成 | 页面错误提示、服务连接和任务状态 |
| 导出一直等待 | 导出任务状态及失败说明 |
| 评估无法启动 | 数据集绑定、预检结果和运行依赖 |

需要管理员协助时提供发生时间、页面、任务标识和脱敏错误信息。“日志中心”和“系统状态”用于进一步定位；部署、数据库维护及服务命令按现有运维文档处理。
