### 常用术语

| 术语 | 含义 |
| --- | --- |
| 知识库 | 按权限组织资料、解析内容并用于问答的资料范围 |
| 会话附件 | 当前对话使用的文件，与知识库上传分别管理 |
| 参考来源 | 回答所引用资料的文件和定位信息 |
| 候选产物 | 待检查或审核的生成结果，不等于正式发布 |
| 私有 / 部门共享 | 知识库所有者控制的访问范围 |
| 长期记忆 | 按授权范围提供的个人或项目辅助信息 |
