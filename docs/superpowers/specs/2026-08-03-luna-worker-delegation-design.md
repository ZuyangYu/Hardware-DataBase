# Luna Worker 项目级委派规则设计

## 目标

在当前工作树的项目根目录创建 `AGENTS.md`，使 Codex 在处理范围明确、可独立执行且可重复的小任务时，优先将任务委派给全局自定义子代理 `luna_worker`。

## 作用范围

规则放在项目根目录，因此适用于整个 `template-upload-governed-authoring` 工作树。它不修改全局 Codex 行为，也不影响其他项目或工作树。

## 最终规则

```markdown
# Subagent Delegation

对于范围明确、可独立执行且可重复的小任务，优先委派给 `luna_worker`。
```

## 边界

- 仅新增根目录 `AGENTS.md`，不修改其他项目文件。
- 规则表达“优先委派”，不会要求所有任务都使用子代理。
- 复杂、模糊、强耦合或不适合独立执行的任务仍由主代理处理。
- 是否实际派生子代理仍受当前 Codex 会话的多代理功能、运行时指令和权限约束。

## 验证

- 确认 `AGENTS.md` 位于工作树根目录。
- 重新读取文件并逐字核对最终规则。
- 检查 Git 差异，确保没有将现有的无关改动纳入本次变更。
