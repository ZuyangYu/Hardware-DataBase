# 异常优先的 ICD 正式生成设计

## 目标

将 ICD 的确定性管脚取数、范围决策和发布校验接入登录后的正式文档生成流程。高置信度事实自动采用；用户只处理范围、裁剪和冲突等少量例外；候选文档在一次整体批准前不得发布。

## 范围

本设计覆盖知识库工作单中的 ICD 类表格生成：接插件范围、管脚定义、型号、功能描述、备注，以及模板中存在时的“板端接插件前视图管序布局和定义”。它不把任何项目、位号、网络名或模板坐标写入代码。

## 决策模型

### 自动采用

系统将模板字段语义与 CircuitStore 的 EDF 结构化事实结合。下列条件同时成立时，事实自动采用并写入候选输入：

1. EDF 中存在该接插件和对应管脚；
2. 对范围或描述至少存在一份 FPT、需求或其他冻结来源的直接证据；
3. 来源之间不存在相互冲突的值。

每个自动采用项保存来源 ID、来源版本和判定理由，但不要求用户逐项点击。

### 人工待办

系统只为下列例外创建待办：

- 接插件范围只有弱证据或候选来源互相冲突；
- EDF 中存在、但目标 ICD 未声明是否应对外暴露的额外脚，例如 PGND；
- “预留”“功能裁剪”等设计结论没有直接证据；
- 型号、功能或备注的多个直接来源不一致；
- 必填模板字段没有可追溯的来源。

待办的最小展示字段为：`发现的问题`、`系统建议`、`依据`、`你需要做什么`。用户仅可选“采用建议”“排除”“标记待补充”，并可填写简短说明。所有待办在一次提交时批量处理；不出现逐管脚确认页面。

## 数据流

1. 用户登录后选择已授权知识库、受控模板和已批准 Document Schema。
2. 创建工作单时冻结来源集合；模板的管脚字段触发 CircuitStore 关系检索。
3. `IcdScopeDecisionService` 汇总 EDF、FPT、需求等证据，创建范围决策快照和待办清单。
4. 没有待办时直接冻结范围；有待办时页面展示一张异常表，用户批量提交处理结果。
5. Harness 只能使用已冻结的范围决策和来源快照生成候选制品。
6. 生成后执行 ICD 集合校验、只读预览和反馈；用户可提交反馈，但只有“批准并发布”可改变制品发布状态。

## 生成与校验规则

- 管脚表以 EDF 的已选接插件—管脚—网络映射为权威输入；无网络连接的脚输出 `NC` 并保留来源状态。
- PGND 等真实管脚不可静默过滤；若缺少对外暴露依据，必须进入待办。
- 功能描述、型号和备注只写入有直接来源的值；缺少来源时保持待补充，不得由模型猜测。
- 生成前比较“已冻结范围的 EDF 管脚集合”与“待写入 ICD 的管脚集合”。缺失、重复、网络不一致和未处理例外均为阻断发布的问题。
- 人工反馈可补充事实，但不能绕过来源、范围和集合校验。

### 板端接插件前视图

当模板为 ICD 且包含“板端接插件前视图”“管脚定义 / Pin Definition”“管脚号 / Pin Number”等重复横向格位时，系统将其识别为物理管序布局，而不是普通文本或由模型自由排版的表格。

- 模板中已有的单元格坐标、合并关系、左右/上下顺序、颜色和边框是布局权威来源；生成只能填充可写的管脚定义和板端管脚编号，不得重排行列。
- 系统从样例格位中的管脚号或 `位号-管脚号`（例如 `X302-20`）建立“格位 → 管脚号 → 接插件”的映射，再以冻结 EDF 管脚映射填入信号定义和板端编号。
- 同一模板可以有多个接插件前视图；每个布局必须只引用其已冻结接插件范围中的管脚。NC、PGND 与其他真实管脚遵循同一冻结事实，不得隐藏。
- 不能可靠识别接插件、格位管脚号，或布局出现重复/缺失/网络不一致时，产生阻断校验问题；候选可供查看，但不能批准发布。页面必须说明需要补充的是模板中的位号或管脚号布局，而不是要求用户逐管脚重填。

## 用户体验

用户正常路径只有四步：选择来源与模板、查看异常待办（无异常则跳过）、预览候选、一次批准发布。自动采用内容以“已自动确认 N 项”汇总显示，支持展开追溯，但默认不占用用户注意力。

## 测试与验收

1. 单元测试：高置信度自动采用、弱证据待办、冲突待办、PGND/NC 保留、批量处理与范围冻结。
2. 服务测试：未处理阻断待办时 Harness 不得生成或发布；已处理后只能使用冻结决策。
3. UI 测试：待办展示四个说明字段，批量提交后不再逐项要求确认，预览/反馈/批准仍可用。
4. 端到端回归：将真实 EDF、FPT、需求和 ICD 模板上传到知识库，以登录工作流生成候选；验证管脚定义集合与 EDF 完全一致，并与人工 ICD 输出差异报告。

## 非目标

- 不根据位号前缀自动认定接插件范围；
- 不用人工 ICD 作为新项目生成时的输入；
- 不自动发布存在未处理例外或阻断校验问题的候选文档。
