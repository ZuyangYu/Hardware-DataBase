# 示例 ICD 模板自适应生成设计

## 目标

允许用户复用含 `X302` 等示例数据的 ICD 工作簿作为版式蓝本。系统从已解析
EDF 发现真实接插件，默认选择全部可用接插件并允许用户调整，再为每个选择项
生成完整的管脚表和前视图。成品中不得残留样例位号或样例产品数据。

这项能力补充而不削弱正式 ICD 的证据和发布门禁：样例值不再被当作要去 EDF
查找的工程位号，也不允许被猜测映射为某一个真实接插件。

## 范围和非目标

范围包括：XLSX/XLSM 的示例 ICD 模板、连接器选择、EDF 管脚映射、知识库中的
功能/预留/型号证据、可重复管脚表和前视图的填充、来源追溯与发布校验。

不在范围内：根据 `X302` 的名称、管脚数或位置自动推断它等价于 `X1903`；从
没有直接管脚依据的检索文本或模型推理中编造功能描述；改变普通文档或正式 ICD
模板的现有流程。

## 用户流程

1. 用户选择已解析 EDF 和示例 ICD 模板，创建工作单。
2. 系统把模板识别为 `icd_sample`，从同一来源快照的 EDF 列出可用接插件，例如
   `X1900`、`X1902`、`X1903`、`X2000`。
3. 选择页默认全选，并展示每个接插件的位号、型号（如有）和解析到的管脚数；用户
   可取消不需要对外输出的项。至少保留一个选项才能继续。
4. 系统冻结选择和来源快照，将每个选择项的 EDF 管脚映射作为 ICD 的结构化事实。
5. 系统按“连接器-管脚”直接证据补充功能、预留、型号等字段，生成候选文件，
   再执行集合、样例泄漏和来源校验。
6. 用户查看候选和待办后，按现有审核/批准流程发布。

用户不选择连接器时，工作单停在选择页；不会将示例位号提交给 EDF 查询。

## 数据和填充规则

| 目标内容 | 事实来源 | 写入规则 |
| --- | --- | --- |
| 接插件位号、管脚号、网络/对端、NC | 已冻结的 EDF 解析结果 | 每个已选接插件完整写入；不可由知识库文本覆盖 |
| 板端型号 | EDF 元件属性，其次需求/FPT 的直接来源 | 有来源才写入；多个直接值冲突时创建待办 |
| 功能描述、预留、备注 | FPT、需求、HSI 等被分类为权威的知识库来源 | 仅接受包含同一 `位号-管脚号` 的直接证据；无证据留空/待补充 |
| 前视图 | 示例模板的格位结构加上 EDF 管脚映射 | 复制为每个已选接插件的布局；管脚定义与管脚表共用同一映射 |

行级来源至少保存 EDF 源文件、连接器、管脚和任何补充证据的来源 ID。功能字段
缺证据不是 EDF 映射缺失：前者允许作为待补充字段存在，后者阻止生成和发布。

## 模板变换

示例 Profile 保留其工作表、格式、合并单元格、列宽、行高、边框和重复表结构。
模板分析额外标识“示例连接器块”及其可重复的管脚表/前视图格位：

- 每个已选真实接插件复制一个完整块，并替换块内的示例位号、型号和管脚相关内容；
- 对表格行按 EDF 实际管脚数扩展或收缩，避免将 `X302-1`、`X302-19` 或样例网络
  留在结果中；
- 对不能按样例几何可靠复制的前视图，创建阻断待办，要求用户提供可定位的布局，
  而不是写入猜测的格位；
- 生成后的扫描将样例产品标记、样例位号和未替换样例管脚视为阻断问题。

正式 `icd` Profile 仍走原有“模板声明的连接器范围”流程。只有 `icd_sample`
Profile 才进入上述选择与变换路径。

## 组件边界

- EDF 目录组件：在已冻结来源中列出真实连接器及其管脚数量，不负责功能语义。
- 连接器选择组件：保存默认全选后的用户选择，并绑定来源快照。
- 示例模板编译组件：从样例模板获得可重复块和可写槽位，不读取项目工程数据。
- ICD 事实组件：以已选 EDF 映射和管脚级知识库证据构造每个连接器的事实表。
- 渲染组件：把事实表写入已编译的块；不自行检索、不选择范围。
- 校验组件：检查范围冻结、EDF 集合一致性、行级来源、模板样例泄漏与前视图一致性。

## 错误处理和发布规则

- EDF 没有可用连接器：提示重新上传/解析 EDF，不能创建选择结果。
- 用户选择的连接器在来源快照中不存在：提示刷新来源后重新选择，不能沿用旧选择。
- 任意已选连接器没有 EDF 管脚映射：阻断，不把它降级为功能字段待补充。
- 功能、预留或型号缺少直接证据：保留空值和对应待办；候选可查看，发布是否阻断遵循
  模板字段的必填约束。
- 连接器块或前视图不可复制：阻断示例自适应生成，提示需要的模板结构。
- 成品发现样例标记或样例管脚：阻断候选审核和发布。

## 测试和验收

1. EDF 目录测试：真实接插件和管脚计数来自解析结果，示例 `X302` 不在候选中。
2. 选择测试：默认全选、取消选择、来源快照变化和空选择均符合规则。
3. 生成测试：一个样例 `X302` 块为 `X1903` 生成正确的 EDF 管脚号、网络/对端和
   `NC`，成品没有样例位号。
4. 证据测试：只有精确匹配 `X1903-<pin>` 的权威来源可填充功能/预留；无匹配值不
   得由模型生成。
5. 回归测试：正式 ICD 模板仍使用模板声明范围；示例模板不会再触发“EDF 中缺少
   X302 映射”的错误。
6. 发布测试：样例泄漏、EDF 集合差异、未冻结选择和不可复制前视图均不能发布。
