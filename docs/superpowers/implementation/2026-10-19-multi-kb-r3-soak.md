# R3 15 分钟隔离持续检索实测

## 范围

按 900 秒新请求窗口、4 个并发请求线程持续轮换 1/2/4 库，使用既有隔离部署 `/tmp/hdb-r3-live-20261016-01` 的四个选定来源及真实 RAGFlow。约 900 秒停止接收新请求，排空在途后总耗时 **906.499 秒**，进程返回 0。

检索、授权、调用预算和融合由当前测试进程的生产服务代码执行；检索代码基线为 `3011b3a`。隔离目录中的 catalog API 启动基线为 `4f6fc5e`，只用于核对已解析资料，不把这个组合称为当前完整 API/Worker 部署验收。没有调用回答模型或生成正式文档，没有上传新资料、改变共享权限或修改部署开关。

固定锚点采用 `multi_kb_r3_live_anchors.jsonl` 中的单库电压、双 EPS 对比和四源覆盖三题，绑定指定 KB 和事实。它们由编码代理依据原文核对，仍不等于独立人工相关性标签。

总计 **635 请求 / 3,592 实际检索调用**。各请求检索状态、选定来源身份、融合覆盖、固定事实锚点和调用预算均通过；最大每请求调用 **12/24**，最大上下文保守估计 **7,822/8,000**。上下文估计是融合器预算，不是模型计费 token。

线程池最大执行线程 8，pending 容量 256。pending 包含运行与等待的工作，实测峰值 **16**，运行结束前为 **0**，随后关闭本进程的检索池与后端并退出。该数据不表示整个主机或其他服务线程已停止。

本轮实测保留时间和请求数，不将 15 分钟解释成已经满足尚未给定的生产长稳时长或 SLO。p95 是该主机、该样本和混合并发下的观测值，不含回答模型/Office 生成/审批耗时。

## 原始产物与复现

本地目录：`storage/evaluations/multi-kb-r3-soak-20261019/`。

- `soak.py`：本轮脚本，固定 900 秒/并发 4/轮换三类请求。
- `samples.jsonl`：每请求耗时、调用数、状态、来源覆盖、证据 ID、锚点得分、线程池和资源采样；不复制完整检索原文。
- `report.json`：配置、开始时间、代码/资料版本、汇总与最终排空状态。
- `progress.json`：每 30 秒更新的过程状态。

```bash
HDB_ENV_PATH=/tmp/hdb-r3-live-20261016-01/active.env \
  uv run python storage/evaluations/multi-kb-r3-soak-20261019/soak.py
```

重跑时先保留原始运行目录，给本地脚本及输出选择新的运行目录；隔离服务和来源应仍存在，并重新核验 manifest 中的 KB ID/资料哈希。测试没有停止既有隔离 API/PG/Redis，也没有触碰其他容器。
