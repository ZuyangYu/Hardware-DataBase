# ⑤ 上下电时序表 + 时序图

把 ③ 电源架构的轨序约束与各芯片手册的 Power Sequencing 章节落成两张交付物：时序表（xlsx）+ 时序图（drawio + PNG 双交付）。SKILL.md 路由表定位：必需输入 = 参与芯片清单、各芯片手册时序章节、电源时序。

## 一、输入

1. **③ 电源架构**：轨上下电顺序的物理约束——哪条轨必须先于/后于哪条轨（电源树拓扑 + 电源芯片使能/软启动特性决定），作为整板排序骨架；
2. **各芯片手册 Power Sequencing / Recommended Power-Up 章节**：每颗参与芯片的上下电要求，**记章节表号**（三源铁律的手册来源口径，SKILL.md 第四节纪律 1）；
3. **参与芯片清单**：从 ① 器件清单 / ③ 电源计算表取，范围按用户口径，不自行扩展。

## 二、必含确认项（开跑前弹问）

1. **上电顺序**：整板上电次序——初稿按"core 早于 IO"占位，必须以各芯片手册 sequencing 章节逐轨校订后向用户确认（见第五节原则 1）；
2. **轨间延迟来源**：手册推荐值 vs 实测——两种都合法但口径必须标注（手册值记章节表号；实测值标测试条件）；手册与实测都没有的轨间延迟 → 标"待打合"列入确认清单；
3. **下电是否逆序**：逐芯片确认手册是否要求下电逆序，整板下电方案随之确定。

〔本节为初稿推断，待 owner 校订。〕

## 三、时序表（xlsx）

列结构（定稿）：

| 列 | 口径 |
|---|---|
| 步骤序号 | 全表连续编号；上电块与下电块分段 |
| 动作对象 | 谁的动作：电源芯片使能 / 轨建立 / 释放复位 / 芯片就绪等 |
| 轨/信号 | 轨名与 ③ 电源计算表一致，信号名与 ② 框图一致 |
| 相对延迟 | 相对上一步的延迟；数值来源标注在依据出处列 |
| 条件/触发 | 触发方式：使能脚 / POK（电源好信号）/ 延时 / 手册要求等 |
| 依据出处（记章节表号） | 如"XX 手册 §8.4 Table 23"；用户确认记录标日期 |

- 版式（深蓝表头斑马纹、openpyxl 行列自适应、冻结表头）引用 table-style.md；
- 数值三源铁律全文适用：芯片手册（记章节表号）/ 设计指南/参考设计 / 用户确认记录，三者都不占 → 标"待确认/待打合"列入确认清单，绝不估算；
- 表尾备注区：待打合项、口径说明（与 ③ 表尾备注区同机制，降级为备注不丢信息）。

## 四、时序图（drawio + PNG 双交付）

- **横向时间轴 + 每轨一行**：时间从左到右，每条轨占一行；上电段与下电段在时间轴上分列；
- **正交线**：轨状态用水平线段表达，跳变处用垂直线段——禁止斜线（斜线属 scan_issues.py 检测项）；
- **上电沿/下电沿画法**〔初稿推断，待 owner 校订〕：上电沿 = 垂直上升到高电平段；下电沿 = 垂直下降；相邻两轨上电沿的水平间距表达轨间延迟，与时序表"相对延迟"列一一对应；
- **字号**：独立标注统一字号沿用 02 的 fs25 基准（02 第 4 节"时序图等专用图字号自成基准（见 05-sequencing.md）"——本图基准即 fs25，块内文字随块自适应的规则不适用于独立标注）；
- **标签不骑线**：edge 标签 offset 偏移到线旁（竖线标签放线右侧、横线上标签放线上方），不依赖 labelBackgroundColor 白底（PNG 导出中不可靠）——02 第 4 节；
- **工程内部信息不上图**：待打合字样、POK 等内部信息只留表格表尾，不上图——02 第 5 节；
- **双交付缺一不可**：drawio（可编辑）+ 同名 PNG——导出四坑照 02 第 6 节办理；
- **三道闸第一道照跑**：scripts/checks 工具链对时序图同样适用（检测脚本是 mxGraph/drawio XML 的通用几何分析器，可直接对任何 drawio 文件运行——SKILL.md 第六节）。

## 五、原则

1. **core 早于 IO 类顺序只作占位**：通用经验顺序只用来起草，定案必须以各芯片手册 sequencing 章节为准逐轨核对——两者冲突时手册赢，仍占位未定的轨序标"待打合"；
2. **未决处标"待打合"**：手册缺 sequencing 章节、轨间延迟无来源、下电顺序手册未写——全部进待打合清单与确认清单，不留空也不猜；
3. **改一步验一步**：调整轨序/延迟后，时序表与时序图同步改、同步核对（表"相对延迟"列与图上沿间距一一对应），禁止只改一头。
