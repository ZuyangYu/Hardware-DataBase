# ⑥ 热风险分析表

逐芯片结温核算与热风险分级，交付一张 xlsx（全公式链）。SKILL.md 路由表定位：必需输入 = ③ 的功耗数据、**Ta 出处（查需求，勿惯例假设）**、各芯片手册热阻。

## 一、输入三件套

| 输入 | 口径 | 出处要求 |
|---|---|---|
| Pmax | 芯片最大功耗，口径 = **负载最大耗流**折算（P = V × I_max）——与 ③ 的校验口径"电源输出电流能力 > 负载最大耗流"同源（03 第一节） | 取自 ③ 电源计算表 max 块，禁止另行估算；③ 中标"待确认/待打合"的耗流值随带着标 |
| Ta | 环境温度 | **必须问用户出处**（见第二节），禁止惯例假设 |
| RθJA / RθJC | 结-环境 / 结-壳热阻 | 各芯片手册热阻（thermal 信息）章节，**记章节表号** |

## 二、必含确认项（开跑前弹问）

**Ta 出处**：环境温度取值必须向用户确认来自哪份依据——手册工况（芯片手册给出的工作环境温度）/ 项目环境（产品工作环境定义）/ 客规（客户规范要求）。禁止按 25°C / 85°C 之类惯例假设——Ta 直接抬升全部 Tj，取错一度全表错。〔SKILL.md 路由表 ⑥ 行加粗项〕

## 三、计算（Excel 全公式链）

- **公式**：Tj = Ta + P × RθJA；
- **全公式链**：Ta、Pmax、RθJA、允许结温为输入格；Tj 格 = 公式；结论格 = 规则化比较——改任一输入（含 ③ 功耗更新后回填）自动重算，不填死数；
- **公式单格单逻辑**：一格只放一层逻辑（与 ③ "一格一逻辑"同规则，03 第三节），复杂拆分拆成多列，不写嵌套长公式。

## 四、判定

- **对比基准**：允许结温（芯片手册 Absolute Maximum Ratings / Operating Junction Temperature 章节，记章节表号）与**降额政策**（用户提供或客规；暂无降额政策时按允许结温直比并在表尾注明〔初稿推断，待 owner 校订〕）；
- **风险分级**：
  - ✓：Tj 低于降额后限值，有裕量；
  - 临界：接近降额线，裕量不足；
  - 超规：超过允许结温或降额线；
- **超规与临界都进"待打合"标注**，列入确认清单（换封装 / 降功耗 / 加散热手段），与三源铁律"列入向用户/厂商的确认清单"同机制（SKILL.md 第四节纪律 1）。

## 五、表结构（列定稿）

芯片 | 封装 | Pmax(来自③) | RθJA(出处) | Ta(出处) | Tj(公式) | 允许结温 | 结论

| 列 | 口径 |
|---|---|
| 芯片 | 名称+型号，与 ①③ 同一口径 |
| 封装 | 封装型号——热阻随封装变，必须落列 |
| Pmax(来自③) | 引 ③ 的 max 功耗，注明轨/耗流来源 |
| RθJA(出处) | 数值 + 章节表号 |
| Ta(出处) | 数值 + 来源（手册工况/项目环境/客规——第二节确认结果，标日期） |
| Tj(公式) | 公式格，自动重算 |
| 允许结温 | 数值 + 章节表号 |
| 结论 | ✓ / 临界 / 超规（规则化判定）；临界、超规在备注标待打合 |
