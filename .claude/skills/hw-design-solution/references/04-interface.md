# ④ 接口定义表

接插件 pin 定义表的全部规则。pin 规则来自用户工程经验，一旦定错返工成本高。

## 一、必含确认项（开跑前弹问）

**pin 序排列方式**：双排接插件按"上排 1~N → 下排 N+1~2N"（Pin1 与 Pin(N+1) 上下正对，编号沿排连续），还是奇偶交叉（上奇数下偶数，Pin1 对 Pin2，板对板连接器常见）？连接器厂家间不一致，必须显式确认，不可默认。

## 二、Pin 数纪律

接插件 pin 数必须为双数——实际中不存在单数接插件。唯一例外：只有一个信号接口（如单对差分的 2Pin 以太网连接器）。

## 三、信号排布三原则

1. 一对差分线的 P/N 必须同一排相邻（方便同侧走线），禁止跨排；
2. 高速差分对（LVDS 等）对与对之间用 GND 隔开，高速区首尾用 GND 包裹；
3. 高速区与低速信号区之间加 GND 隔离带；电源 pin 集中放置 + 回流 GND 相邻。

自检方法：排完后按"差分对内相邻、对间 GND、高速/低速隔离带、电源集中"逐条过。

## 四、单 pin 过流要求（必须提出）

按"实测电流 ÷ 并联 pin 数 + 降额"提出选型要求：

- 实例口径：入口 9V 3A÷2pin=1.5A → 要求 ≥2A/pin；其余电源/地 pin 统一 ≥1A/pin；信号 pin 填"—"；
- 电流数值只能取自电源计算表的 max 列（三源铁律见 03-power-calc.md），绝不估算；待打合项在过流列备注里标明。

## 五、表结构（6 列定稿）

接插件编号 | 接插件名称 | Pin编号 | Pin定义（网络名） | Pin作用 | 过流要求。

- 每个接插件一个 sheet；
- 表尾备注写明：pin 序排位与正对关系、差分/隔离布局说明、过流依据（电流出处）；
- 网络名与整体硬件方案框图严格一致，不得发明框图上没有的信号。
